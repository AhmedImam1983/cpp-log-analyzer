# C++ Log Analyzer

A simple C++17 application built with CMake.

## Features

- C++17
- CMake-based build
- Compiler warnings enabled

## Requirements

- C++17 compiler
- CMake 3.20+

## Build

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Release
cmake --build build --parallel
./build/log_analyzer
